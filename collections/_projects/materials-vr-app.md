Virtual reality app for iOS and Android to allow students to visualize molecular structures.

<!--more-->

Project with Professor Schleife for the NCSA SPIN program at UIUC (2017)

## Features

https://github.com/aschleife/MaterialsVR

- Auto-generating molecule list
- Gaze input - stare at a button or object for 2 seconds to select it (hands-free)
- Rotate molecules
- Drag and drop molecules to any position

## My Contributions

I was responsible for all aspects of development for the iOS and Android versions of this app:

- Unity Asset Bundles - utilizes Asset Bundles to pull molecules from our webserver, making app content updates easier and reducing the download size
