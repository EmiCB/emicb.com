{%- comment -%} Renders the status badge for a game (shipped, in development, or paused), with the label and icon sourced from _data/game-statuses.yml. Renders nothing if no status is given or the status isn't in the data file. Usage: {% include game-status-badge.html status=page.status %} Params: - status (optional): key from _data/game-statuses.yml (shipped, in-development, paused) {%- endcomment -%} {%- if include.status -%} {%- assign game_status = site.data.game-statuses[include.status] -%} {%- if game_status -%} {{ game_status.icon }}{{ game_status.label }} {%- endif -%} {%- endif -%}
